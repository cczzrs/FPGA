采集链路

  1. OV9281输出 RAW8 / RAW10 灰度像素
  2. Icepi Zero解串、解析 CSI-2 并检查行 CRC
  3. SDRAM缓存完整帧，支持 1 至 20 帧
  4. USB 串口2 Mbaud，逐行回传至本机
  5. 本机网页预览、保存 PNG 与曝光合成

运行实体相机

公开站点提供浏览器成像演示。实体拍摄、寄存器读写和 FPGA 烧录通过连接开发板的电脑运行。下载包包含 RTL、引脚约束、构建脚本、仿真、接线说明和本机控制台。

python3 -m pip install pyserial numpy
./build.sh
openFPGALoader -b icepi-zero build/cam.bit
python3 host/server.py --port /dev/cu.usbserial-实际编号

将串口示例替换为系统中的实际设备，然后打开 http://127.0.0.1:8000。构建和烧录需要相应的 FPGA 工具，接线详见下载包中的 README。
